CompanyOS Phase 28001-30000 — Autonomous Company Operating Loop

Connects the operating lifecycle into a persistent governed cycle:
Discover -> Research -> Select -> Plan -> Budget -> Build -> Test ->
Launch Review -> Operate -> Customers -> Revenue -> Accounting ->
Evaluate -> Portfolio Decision -> Learn -> repeat.

This bundle adds orchestration/governance scaffolding. Existing CompanyOS
specialists and adapters remain the source of real capabilities.

Safety boundaries:
- treasury policy remains enforced outside autonomous reasoning
- irreversible actions require approval
- external launch actions remain gated
- live money movement is NOT automatically enabled by this bundle

Install:
cd ~/companyos
cp /sdcard/Download/CompanyOS_AUTONOMOUS_OPERATING_LOOP_30000.zip .
unzip -o CompanyOS_AUTONOMOUS_OPERATING_LOOP_30000.zip
bash companyos_phase28001_30000/install.sh ~/companyos

CompanyOS Phase 50001-52000
CONTROLLED LIVE READINESS GATE

Purpose:
Prepare CompanyOS for a tightly controlled first live transaction review without enabling unrestricted autonomous money movement.

Adds:
- live-readiness prerequisite evaluation
- one-shot authorization token
- time-to-live expiration
- maximum amount cap
- destination lock
- single-use enforcement
- treasury, kill-switch, and receipt-verification requirements preserved

Important:
AUTONOMOUS_LIVE_ENABLED remains FALSE.
This phase does not broadcast a transaction by itself.

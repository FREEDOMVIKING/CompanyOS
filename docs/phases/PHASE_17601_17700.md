# CompanyOS Phase 17601–17700

## Autonomous Portfolio Director

This bundle adds:

- venture health scoring,
- cross-company ranking,
- scale/continue/repair/pause decisions,
- guarded capital recommendations,
- reserve planning,
- executive portfolio dashboards,
- persistent decision history.

The module produces recommendations only. It does not transfer funds, alter wallet permissions, bypass transaction caps, or perform external actions.

python -m py_compile companyos_modules/phase17601_17700/portfolio_director.py
